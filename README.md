# SANGEETHA | Handcrafted Wooden Furniture & Bespoke Living

A handcrafted web experience for SANGEETHA Furniture Studio, celebrating authentic Kerala teak carpentry, mortise-and-tenon joinery, and bespoke living room suites.

## Features
- **Sofa Gallery**: High-resolution catalog showcasing real teak spindle sets, royal salon suites, and daybeds.
- **Pure Photo Lightbox**: Clean full-screen image viewer with keyboard navigation (`←`, `→`, `Esc`).
- **Interactive Delivery Lorry**: Dynamic scroll-driven animated Kerala timber transport along coastal roads.
- **Direct WhatsApp & Phone Consultation**: 24×7 connectivity directly with master artisans (+91 85928 09092).
- **Zero Distraction Experience**: No ads, no popups, purely focused on Kerala heritage craftsmanship.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Node.js local dev server (`server.js`)

## Running Locally
```bash
node server.js
```
Then visit `http://localhost:3000` in your browser.
